## 一、核心结论（一句话）

澳门那套「分数碾压」的逻辑在香港**不成立**——香港 2024-11 改革后取消了人才清单加分、改为 12 项准则准入制。
但你的**收入**在香港是硬通货：高才通 A 类唯一硬门槛就是年收入 ≥ **HK$250 万**，不看学历、不设配额、4–8 周出结果、获批率约 81%。

**→ 主攻 A 类，优才作保底并行评估。**

**压力测试**：
- ✅ 公积金全额剔除 → 仍过线（北京缴存上限，个人部分年约 5 万，缓冲 29.5 万）
- ✅ 汇率回到 0.92 → 约 HK$265 万，仍过线

⚠️ **但 A 类看的是「紧接申请前 12 个月」滚动窗口，不是自然年。**
若 414,575 股权收益为某月集中归属，**递交窗口必须罩住该月**。

## 四、与澳门仓库的材料复用关系

澳门 29 项材料里约 **20 项可直接复用**（口径几乎一致）：身份证明、学历、腾讯工作证明、个税、社保、福布斯榜单截图等。

| 类别 | 说明 |
|---|---|
| ♻️ **直接复用** | 身份证明、腾讯在职/工作证明（含收入字段）、个税纳税记录、社保记录、福布斯榜单截图、无犯罪记录（10 年居住清单两地规则相同，一次整理两地受益） |
| ✍️ **必须重写** | 赴港计划书（若走优才）——香港唯一能让 gamescom 奖项发力的地方，权重最高 |
| 🆕 **香港独有** | **《赴港工作同意书》** ID(C)1026 附件 —— 内地居民特有，澳门没有。由腾讯 HR 或赤峰红山区人才中心（档案编号 6981）出具 |
| ➖ **完全省掉** | **学历文件**——A 类官方核对清单里学历件只属于 B/C 类，毕业证/成绩单/学信网认证**全部不需要** |

## 七、长期提醒：A 类「获批不难，续签难」

2026 年起「无条件延期 1 年」已关闭。36 个月后要过**「两址两单」穿透核查**（居住地址 + 办公地址 + 薪俸税单 + 强积金）。

主业在深圳的现实下，建议把 A 类定位为 **3 年期可续的灵活身份**，而非必然的永居通道。
若真要奔永居，需提前布局**香港主体真实业务 + 薪俸税记录**（见 `01_申请攻略/02_高才通A类_申请流程与材料准备手册.html` 第六章）。
