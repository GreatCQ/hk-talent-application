## 一、🔴 重大变化：人才中心路径已关闭（必须先看）

**2026 年 8 月起，香港入境处明确不再接受由「人才服务中心 / 人才市场 / 档案保管单位」盖章的赴港工作同意书（无工作者除外）。**

对**在职人员**，现在只有一条路：**现任职公司盖章**。

### 四项硬性要求（缺一即补件/退件）

| # | 要求 | 说明 |
|:--:|---|---|
| 1 | **现任职工作单位/公司盖公章** | ❌ 不接受人才中心、人才市场、档案保管单位章 |
| 2 | **公司负责人签署** | ❌ **不接受申请人自行签署**（这点最容易被忽略） |
| 3 | 同意书须**明确写明**「根据**高端人才通行证计划**赴港」 | 泛泛写"同意赴港工作"不行 |
| 4 | **需一并提交盖了公章的社保证明** | 🆕 v1 完全漏掉的材料，见第五节 |

### 一个必须先说明的矛盾

官方 ID(C)1026（03/2026）附件表格上**仍印着**「本工作單位／**檔案所在單位**」——表格文字没改，但实操口径已收紧。

**→ 以实操口径为准：在职就走公司盖章，别赌人才中心。**

## 四、⚠️ 盖章主体必须与申请表一致（高频拒签点）

2026 年高才通高频拒签案例中，相当一部分是**同意书盖章单位与申请表填写的工作经历不匹配**——
例如申请表写正在 A 公司任职，同意书却由 B 人才市场盖章，直接认定材料矛盾。

### 你的情况有个必须先确认的点

- 你在**深圳**工作（腾讯 IEG V3 产品部副总监）
- 但收入证明是**腾讯科技（北京）**出具的
- 你另有**日蚀边缘 Eclipse Glow Games** 联席 Co-CEO & COO 身份

**→ 盖章主体必须是「劳动合同签约主体」，且与申请表填写的现职完全一致。**

- [ ] 确认劳动合同签约主体全称：________________（腾讯科技（深圳）／腾讯科技（北京）／其他）
- [ ] 确认申请表"现时工作单位"将如何填写
- [ ] 两者**必须逐字一致**

> 建议：同意书、收入证明、社保缴纳单位、申请表四处口径统一。四处不一致 = 材料链条断裂。

## 五、🆕 配套材料：盖公章的社保证明

2026-08 新要求，**v1 完全漏掉了这一项**。

- 需提交**盖了公章的社保证明**
- 缴纳单位应与同意书盖章单位、申请表现职**一致**
- 建议拉取近 12 个月，与递交窗口对齐

领取渠道：深圳社保局线下窗口 / 粤省事 / 深圳人社公众号（线上版需确认能否加盖公章）

## 八、时间风险与推进建议

| 项 | 说明 |
|---|---|
| 🔴 用印周期不可控 | 大厂公章审批可能需数日至数周，**本周就要发起** |
| 🔴 无备选路径 | 人才中心路径已关闭 → 公司这条线没有 Plan B |
| 🟡 敏感性 | 等于让公司知悉你办香港身份。但澳门优才的收入证明已由腾讯出具，**公司已知晓你在办人才引进**，不算新增披露，敏感性可控 |
| 🟡 四处口径 | 同意书 / 收入证明 / 社保 / 申请表，四处单位名必须一致 |

### 建议动作顺序

1. **今天**：把官方表格 PDF 下载下来（`https://www.immd.gov.hk/pdforms/ID(C)1026.pdf`），填好简体版
2. **今天**：发微信探口风，问用印流程与周期
3. **本周内**：正式邮件递交 + 附表格
4. 同步拉社保缴纳证明（盖公章）

## 九、常见退件雷区汇总

| 雷区 | 后果 |
|---|---|
| 同意书由人才中心 / 人才市场盖章（在职人员） | 🔴 退件 |

| 公章不清晰 | 🟡 补件 |

| 缺盖公章的社保证明 | 🟡 补件 |
